Gus is built from a few bold shapes with thick charcoal outlines — a teal blob, cream eyes, orange cheeks, a sprout + spark, and a cream belly badge with a checkmark (Gut Check → “correct”). Clean separable parts (eyes, mouth, arms) so he can blink, bob, and react. Warm, curious, a little cheeky — encouraging, never mean.

Outlines
Thick charcoal strokes on everything, slightly rounded corners, and a chunky “hard offset” shadow (solid charcoal, a few px down). Sticker, not gradient.

Type
Wordmark: heavy rounded sans, slight tilt — Gut in orange, Check in teal, cream rim. Body/UI stays rounded and friendly; never thin.

Icon
Rounded-square tile (~22% radius), teal by default. A simplified Gus face + belly check. Reads at 48px and as a favicon. theme-color = teal #00A79B.

Mascot
Lead with Gus so it’s warm for kids and adults. Subtle motion only: idle bob + blink, a little pop on celebrate. Swap expression by game state.

Don’t
No fine detail, photoreal, gradient-heavy rendering, tiny text inside the icon, or dark/cyberpunk. Keep shapes bold and few.

Deliverables
Vector SVG (transparent) + PNG 512/192/48 + favicon, mascot expression PNGs, deck badge PNGs, and a 1200×630 OG. The in-app wordmark is a CSS build of this same mark.
